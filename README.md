# Mathe-Lernumgebung Oberstufe

Digitale Ergänzung zum Mathematikunterricht der gymnasialen Oberstufe (Klassen 12 und 13, Baden-Württemberg). Die Lernumgebung bietet interaktive Visualisierungen, Entdeckungsaufgaben, Erklärungen und Selbsttests. Die Unterrichtsdokumentation liegt weiterhin im Kursnotizbuch.

## Status

Im Aufbau. Das technische Grundgerüst steht. Über GitHub Pages bereitgestellt werden der Basiskurs „Abitur 2027“ und der Kurs „Abitur 2028“, beide mit den sechs Modulen zu den trigonometrischen Funktionen.

## Grundsätze

- Statische Website ohne Server und ohne Datenbank, gehostet über GitHub Pages.
- Keine Schülerkonten, keine zentrale Speicherung von Antworten oder Lernständen, keine Trackingdienste.
- Kursfreigaben steuern nur, welche Inhalte in der Navigation erscheinen. Sie sind keine Zugangskontrolle, alle veröffentlichten Inhalte sind öffentlich erreichbar.
- Neue oder geänderte Lerninhalte werden erst nach ausdrücklicher Freigabe durch die Lehrkraft veröffentlicht.
